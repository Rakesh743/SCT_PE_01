# SkillCraft Task 01: Writing Better Prompts

### Pair 1: Climate Change
**Vague Prompt:** Explain climate change
**Why it's weak:** 
- Doesn't specify the audience
- Doesn't mention level of detail  
- Doesn't define format of response
**Improved Prompt:** Explain climate change in 3 bullet points for a 12-year-old student. Use very simple words.
**Why it's better:**
- Specifies audience (12-year-old student)
- Limits response to 3 bullet points
- Requests simple language

### Pair 2: Python Code
**Vague Prompt:** Write code
**Why it's weak:**
- Doesn't specify programming language
- Doesn't specify the task
- Doesn't specify audience
**Improved Prompt:** Write a Python function to check if a number is even. Add comments so a beginner can understand.
**Why it's better:**
- Specifies language = Python
- Specifies task = check even number
- Specifies audience = beginner + adds format = comments

### Pair 3: Artificial Intelligence
**Vague Prompt:** Tell me about AI
**Why it's weak:**
- Doesn't specify length
- Doesn't specify audience
- Doesn't specify tone
**Improved Prompt:** Explain what is AI in 5 short lines for a college student. Use professional tone.
**Why it's better:**
- Specifies length = 5 lines
- Specifies audience = college student
- Specifies tone = professional

### Learning
Better prompts = Better AI answers. Adding clarity, specificity, and tone changes LLM behavior completely.
